# خطة تطوير المتجر: واجهتين رئيسيتين (رقمي + مادي CJ Dropshipping) ونظام المصادقة الشامل

تهدف هذه الخطة إلى توسيع منصة **TAREK STOR / SOLO** لتدعم واجهتين رئيسيتين متجاورتين جنباً إلى جنب: متجر المنتجات الرقمية الحالي (شحن الألعاب والبطاقات) ومتجر المنتجات المادية المربوط بـ **CJ Dropshipping**، بالإضافة إلى نظام متكامل للتسجيل وتسجيل الدخول عبر Google وتليجرام والبريد الإلكتروني مع واجهة إعداد المفاتيح والربط السحابي.

---

## مراجعة القرارات والمفاتيح المطلوبة من المستخدم

> [!IMPORTANT]
> **ما ستحتاجه المنصة منك لربط الحسابات الحقيقية والـ API (يمكنك إدخالها مباشرة في لوحة إعدادات الربط بالمتجر):**
> 1. **ربط CJ Dropshipping:**
>    - **CJ API Key (Access Token):** من لوحة مطوري CJ Dropshipping (`developers.cjdropshipping.com`) عبر قسم API Settings.
>    - **CJ Account Email:** البريد الإلكتروني المسجل به حسابك في CJ.
> 2. **تسجيل الدخول عبر Google:**
>    - **Google Client ID:** من منصة Google Cloud Console عبر قسم OAuth 2.0 Credentials (تطبيق ويب).
> 3. **تسجيل الدخول عبر تليجرام (Telegram Login):**
>    - **Telegram Bot Username:** اسم معرف البوت المنشأ عبر `@BotFather` على تليجرام لربط ويدجت تسجيل الدخول.
> 4. **البريد الإلكتروني:**
>    - جاهز للتسجيل المباشر وتأكيد الحساب عبر البريد وكلمة المرور المشفرة.

## 1. الرؤية العامة والتجربة (Dual-Store Concept)

- **الواجهتان الرئيسيتان المتجاورتان (Dual Homepages Switcher):**
  - **الصفحة الرئيسية 1 (المنتجات الرقمية):** شحن شدات ببجي، بطاقات ستيم وبلايستيشن وإكس بوكس، فري فاير، البطولات، والمحفظة الرقمية الفورية.
  - **الصفحة الرئيسية 2 (المنتجات المادية ودروبشيبينغ CJ):** إكسسوارات الجيمنج (سماعات محيطية، لوحات مفاتيح ميكانيكية، ماوسات احترافية، كراسي جيمنج، إضاءات RGB، ومعدات الستريمرز) مع تفاصيل الشحن والوزن والمستودعات والتتبع.
- **التبديل الفوري بين المتجرين:** مفتاح تبديل رئيسي واضح في أعلى الصفحة وفي شريط التنقل (`🛍️ المنتجات الرقمية` ⇄ `📦 المنتجات المادية (CJ)`).
- **نظام تسجيل وتسجيل الدخول (Unified Auth Modal & Screen):**
  - الدخول بضغطة زر عبر **Google**.
  - الدخول المباشر عبر **Telegram**.
  - إنشاء حساب جديد وتسجيل الدخول بالبريد الإلكتروني وكلمة المرور مع استعادة الحساب وتأكيد الشروط.

## 2. تجربة المستخدم والتصميم البصري (UX & Design)

- **سير عمل متجر المنتجات المادية (CJ Dropshipping Storefront):**
  - تصفح المنتجات المادية المصنفة مع خيارات الألوان والأحجام ونوع المقبس الكهربائي.
  - حاسبة الشحن التلقائية (تقدير مدة التوصيل وتكلفة الشحن حسب الدولة والمدينة).
  - صفحة إتمام الطلب المادي (سلة الشراء، إدخال عنوان الشحن الفعلي: الدولة، المدينة، الحي، الرمز البريدي، ورقم الجوال للمندوب).
  - إرسال بيانات الطلب تلقائياً إلى لوحة الإدارة لتحويلها إلى طلب شحن في CJ Dropshipping.
- **لوحة تحكم الدروبشيبينغ وإدارة المفاتيح (CJ & API Settings):**
  - قسم مخصص داخل لوحة الإدمن لإدخال وفحص مفاتيح الربط:
    - اختبار الاتصال مع CJ API بنقرة واحدة (Test CJ Connection).
    - استيراد منتجات جديدة من CJ بواسطة معرف المنتج (Product SKU / CJ PID).
    - إعداد هامش الربح التلقائي (Markup Percentage).
- **صفحة تسجيل وتسجيل الدخول المتطورة:**
  - تصميم داكن عصري متناسق مع هوية المنصة (Cyber Dark + Neon Cyan).
  - تبديل سلس بين (تسجيل الدخول / إنشاء حساب جديد / نسيت كلمة المرور).
  - أزرار دخول موثقة لـ Google و Telegram وأيقونات تفاعلية.

## 4. خطة الخطوات التنفيذية عند الموافقة

1. **الخطوة 1: تحديث نماذج البيانات والحالة (Types & Context):**
   - إضافة نوع المنتجات المادية `PhysicalProduct` (أبعاد، وزن، خيارات ألوان/مقاسات، كود CJ SKU، مدة الشحن).
   - إضافة نموذج بيانات عنوان الشحن للعميل `ShippingAddress`.
   - إضافة إعدادات الـ API للمفاتيح `ApiIntegrationsConfig` (CJ Key, Google Client ID, Telegram Bot).
2. **الخطوة 2: بناء صفحة تسجيل وتسجيل الدخول المتكاملة (Auth Screen & Modal):**
   - تصميم واجهة متكاملة تدعم التبديل بين الدخول والإنشاء، والدخول الاجتماعي عبر Google و Telegram والبريد.
3. **الخطوة 3: بناء الصفحة الرئيسية للمنتجات المادية (Physical Storefront):**
   - كاتالوج احترافي لمنتجات الجيمنج المادية (سماعات، كيبوردات، شاشات، ماوسات، إضاءات).
   - حاسبة الشحن والتوصيل، ونظام سلة تسوق فيزيائية مع نموذج عنوان الشحن.
4. **الخطوة 4: شريط التبديل بين المتجرين في الهيدر والصفحة الرئيسية:**
   - زر محوري في الهيدر يسمح للزائر بالانتقال بسلاسة بين المتجر الرقمي والمتجر المادي.
5. **الخطوة 5: واجهة تكامل CJ Dropshipping وإدخال المفاتيح:**
   - توفير نافذة إعدادات لاختبار وإدخال مفاتيح CJ Dropshipping و Google و Telegram بسهولة وحفظها في إعدادات المنصة.
